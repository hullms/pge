# Broche — Communication avec le codeur numérique

Dans cette broche, il y a deux dossiers qui expliquent la partie communication avec le codeur numérique.

## Partie électronique
Elle regroupe :
- Les schémas des montages (le PCB)
- Les codes informatiques permettant de tester les différentes parties des montages électroniques

## Partie informatique
Elle contient :
- Le firmware pour piloter le montage (PCB)
- La gestion de la communication avec l’interface utilisateur du lecteur KVB
